# Cost Optimization

## Match supply to demand

Use auto scaling and managed or serverless services so that capacity follows traffic instead of being sized for the peak all day. Serve static assets and images from a content delivery network and object storage rather than from application servers.

## Use pricing models that fit steady load

For the steady baseline of a workload, commitment-based pricing such as savings plans or reserved capacity lowers cost. Keep on-demand capacity for the variable part of the load, and consider interruptible capacity for fault-tolerant batch jobs.

## Be aware of expenditure

Tag resources by owner, environment and project so that cost can be attributed. Set budgets with alerts, and review the bill regularly. Unused resources such as idle instances, unattached volumes and old snapshots should be found and removed.

## Optimize over time

Review new service features and instance generations periodically. Right-size resources using measured utilization, and move data to cheaper storage classes as it ages.
