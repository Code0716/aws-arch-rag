# Security

## Protect data at rest and in transit

Encrypt data at rest with managed keys, enforce TLS for all connections, and classify data so that stricter controls apply to personal and confidential information. Restrict access to uploaded objects with least-privilege policies and short-lived pre-signed URLs.

## Manage identity and access

Grant each person and workload only the permissions it needs, use temporary credentials instead of long-lived keys, and require multi-factor authentication for people. Review permissions regularly and remove what is unused.

## Detect and respond

Turn on audit logging for all accounts and regions, send logs to a protected location, and alert on suspicious activity. Prepare and practice an incident response plan before it is needed.

## Protect the network and the application

Place workloads in private subnets, expose only load balancers, and use a web application firewall to filter common attacks. Patch operating systems and dependencies on a defined schedule.
